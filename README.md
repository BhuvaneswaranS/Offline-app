# Offline AI Editor — Version 1

A native Android image editor designed to work without an internet connection.

## Version 1 features
- Pick an image from the Android gallery
- Preview it
- Rotate 90 degrees
- Adjust brightness
- Adjust contrast
- Adjust saturation
- Reset adjustments
- Choose another image
- Save as JPEG to Pictures/OfflineAIEditor

## Offline behavior
No network permission is declared. Image processing and saving are local.

## Build
1. Install Android Studio.
2. Open this folder as an existing Gradle project.
3. Let Gradle sync.
4. Connect an Android phone or start an emulator.
5. Press Run.

Minimum Android version: Android 8.0 (API 26).
